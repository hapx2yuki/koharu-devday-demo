# 安全性の境界と確認記録

このパッケージは、新しい公開ソース・ローカル補助アプリの候補です。既存の本人限定工房の認証や、本番サイトの認証情報を取り込むものではありません。

## 守る情報と境界

1. OAuthのaccess/refresh/ID tokenはNodeプロセスのメモリーとmacOSキーチェーンだけで扱う。環境変数、引数、標準出力、ログ、URL、公開パッケージへ出さない。
2. OSキーチェーンへは同梱のSwiftプログラムからSecurity.frameworkのSecItem APIを使う。保存値は標準入力、読取値は親プロセス専用のパイプFD3で渡す。引数・標準出力・通常ファイルには秘密を出さない。標準出力にはOSStatusの数値だけを返し、保存後は再読取して照合する。構築済みプログラムはソースとCPU種別で区別した本人限定キャッシュに置く。
3. 認証案内は`127.0.0.1`の一時ポートだけで待ち受ける。HTTP Host、パス、メソッド、要求長、state、期限、callbackの重複を検証する。外部公開しない。
4. 初回登録のみ`dynamic_agent_client`を使う。コード交換は公式画面が返したclient IDを使い、再接続では保存したclient ID・本人IDの組が変わることを拒否する。
5. ID tokenはjoseで署名、issuer、audience、exp、iat、nonceを検証する。複数audienceの場合はazpも確認する。未検証のdecode結果でログインしない。
6. 設定ファイルは0700の専用フォルダー内に0600で原子的に保存する。対象ファイルのsymlinkや広い権限を拒否する。refresh token更新は排他で行う。
7. APIや認証サーバーからの生のエラー本文は表示しない。失敗時はHTTPステータスと安全な説明だけを返す。
8. 推論は明示操作のみ。非対応の上限制御引数を送ることや、受信時間を料金上限と呼ぶことはしない。上限・追加クレジットの設定確認がなければ通信しない。

## 実装検査で確認したこと

- PKCE S256、state/nonceの新規生成、tokenが認証URLに含まれないこと。
- 不一致state、登録差替え、期限切れ、重複callback、OAuth拒否の停止。
- RSA署名によるID tokenの検証と、別audience・nonce・本人IDの拒否。
- コード交換先、resource、発行済みclient ID、PKCE verifierの対応。
- キーチェーン書込引数に秘密を含めず、標準入力とFD3を用いること、再読取照合。
- macOS実機で16KB・128KBの架空データを保存・更新・読取・削除でき、通常の標準出力にはOSStatusだけが返ること。
- 保存処理の失敗を認証交換の失敗と区別し、秘密を含まない説明を表示すること。
- 上限未確認時の通信0回。
- Responsesの必須`store: false`・`stream: true`、非対応引数の不在。
- 応答の途中切断は未完了、正式`response.completed`だけが成功になること。
- 非公開の推論イベントを出力へ転記しないこと。

## 実環境で未確認のこと

- このアプリ名による初回動的登録と、戻されたclient IDの保存。
- 実アカウントの認証情報について、macOSキーチェーンへの保存と再読取が完了すること。
- ユーザーの実アカウントのモデル一覧、プラン利用の可否と実応答。
- ChatGPT設定にあるアプリ別利用上限・追加クレジット設定。
- パッケージの一般公開審査や配布。本コードは正式Plugin Creatorの利用実績には数えない。

実環境でこれらを確認するまでは、工房の機能対応表で「認証・プラン利用を実証済み」としないでください。認証とプラン利用は別の合格条件です。
