# 安全性と検証の範囲

公開用とローカル用の入口を分離しています。公開Workerは各要求ごとに新しい読取専用サーバーを作成し、状態変更ツールを登録しません。公開画面での試し注文はブラウザー内だけの架空データです。アプリの再表示・再起動で失われ、注文システムの運用保存には使えません。

入力は型、件数、数量、商品ID、価格、受取枠、締切で検査します。JSON本文は150KBまで、CSVは100KBまでです。外部URLや任意ローカルパスを実行・取得する道具はありません。画面は外部接続なしのCSPを指定し、データをtextContentで表示します。

ローカルのstdioサーバーは、同梱HTMLの読取とstdio通信以外のファイル操作をしません。プロセス自身のメモリーだけを変更します。公開用manifestに所有者の環境変数、固定token、既存の工房URLを転記してはいけません。

## 確認済み

- MCPの道具一覧、global/thread/fileの正規メタデータ。
- MCP経由の注文と取消、在庫・受取枠の対応。
- 同じ依頼の再送、並行注文、サーバー間のデータ分離。
- 公開MCPに変更ツールがないこと。
- 公式SDKのHTTP接続、MCP 2026-07-28のdiscoveryと読取。
- 実際のstdioプロセス起動と道具一覧取得。
- CSVの不明値、数式、異常行の拒否。
- 既知の非公開URL、ローカル個人パス、APIキー形式の混入検査。
- package-lockに固定した依存をnpm auditで検査。

混入検査は限定した文字列パターンの検査であり、あらゆる秘密を発見する保証ではありません。公開前に配布物全体を人が確認してください。

## 未確認

- 公開環境での実HTTP、ホストのCSP・権限・プロトコル対応。

これらはコードと単体テストが存在するだけでは実証済みにしません。公開後の確認結果は工房の記録へ登録し、この配布物に本人限定の証拠やアカウント情報を含めません。
